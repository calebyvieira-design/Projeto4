# Projeto 4 — Repetição, decisão e entrada de dados

Exercícios introdutórios em Dart sobre laços, interrupção de fluxo e leitura de dados pelo terminal.

## Exemplos

- `foguete/teste.dart`: faz uma contagem regressiva e interrompe o laço quando a missão é abortada.
- `foguete/teste2.dart`: mostra a mesma interrupção usando `return` diretamente no programa principal.
- `senha/senha.dart`: repete a leitura até a senha correta ser informada.
- `senha/senha2.dart`: adiciona uma mensagem quando a senha digitada está incorreta.

## Como executar

```bash
dart run foguete/teste.dart
dart run foguete/teste2.dart
dart run senha/senha2.dart
```

Os arquivos são exemplos independentes e não formam uma aplicação única. Eles demonstram `for`, `while`, `break`, `return`, condicionais e `stdin.readLineSync()`.
